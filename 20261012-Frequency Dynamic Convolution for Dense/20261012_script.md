### English introduction and conclusion
#### Introduction
  * Dynamic convolution has become a popular way to make convolution more adaptive. Instead of using one static kernel, methods like CondConv and ODConv keep several parallel kernels and mix them with input-dependent attention. The idea is that each kernel can specialize in something different, so the network gains capacity without adding much computation. 
  However, the authors look at these parallel kernels from a new angle, the frequency domain, and find a problem. In figure (a), we see the frequency responses of the four parallel weights in ODConv. All four curves have almost the same shape: they all emphasize low frequencies and drop off at high frequencies. The t-SNE plot in figure (c) tells the same story. Each small group here contains one point of every color, almost on top of each other. In other words, the filters from the four weights are nearly indistinguishable, so the extra kernels are not really learning anything different.
  This matters because these methods multiply the parameter count, typically by four or even eight times. If the extra kernels end up redundant, we pay a large parameter cost for very limited gains in adaptability. Frequency diversity is also especially important for dense prediction tasks like detection and segmentation. Low-frequency components help suppress noise, while high-frequency components capture edges and object boundaries. 
  To solve this, the authors propose Frequency Dynamic Convolution. As figures (b) and (d) show, the resulting kernels now cover different parts of the spectrum and the four weights are now easy to tell apart.
#### Conclusion
  * This paper revisits dynamic convolution from a frequency perspective. The key finding is that the parallel kernels in existing methods have highly similar frequency responses, which wastes a large number of parameters. FDConv learns frequency-disjoint weight and modulates frequency bands spatially, makes it outperforms previous methods while having much smaller parameter size.
